【重要】ダウンロード時・起動時の警告・実行手順について

当ソフト（taitai2661）は個人が開発したプログラムのため、ダウンロード時や初回起動時に各種OSのセキュリティ機能（Windows SmartScreen / macOS Gatekeeper など）によって警告が表示される場合があります。

これは、有料のデジタル署名（証明書）が付与されていない未検証のファイルに対して自動的に発動する安全装置の仕組みによるものです。ウイルスや不正なプログラム等の有害な処理は一切含まれておりませんので、ご安心ください。

お使いの環境（OS・ブラウザ）に合わせて、以下の手順で解除・実行を行ってください。

🌐 ブラウザで「危険なファイル」「安全にダウンロードできません」と出る場合

  • Google Chrome: 画面下のダウンロード履歴（または Ctrl + J / Cmd + Option + L）を開き、「危険なファイルを保持」または「継続」を選択します。
  • Microsoft Edge: ダウンロード画面の「…」をクリックし、「保存」➔「保持する」を選択します。
  • Safari: ダウンロードブロックが出た場合、許可を選択して保存してください。

💻 Windows の場合

「WindowsによってPCが保護されました」と表示された場合：

  1. 画面内に表示されている 「詳細情報」 をクリックします。
  2. 右下に表示される 「実行」 ボタンを押すとアプリが起動します。

🍎 macOS の場合

「開発元を検証できないため開けません」と表示された場合：

  1. Finderで対象のアプリ/ファイルを Controlキーを押しながらクリック（または右クリック） し、「開く」を選択します。
  2. 確認ダイアログが出たら、もう一度 「開く」 をクリックします。
  3. ※上記で開けない場合は、システム設定 ➔ プライバシーとセキュリティ を開き、一番下までスクロールして「このまま開く」をクリックしてください。

🐧 Linux (Ubuntu等) の場合

ファイルをクリックしても起動しない／「アクセス権がありません」となる場合：

  1. ターミナルを開き、実行権限（`+x`）を付与します：
    chmod +x taitai2661
  2. そのままターミナルから実行するか、ダブルクリックで起動します：
    ./taitai2661
※ご不安な方は、GitHub等で公開しているソースコードをご確認いただくか、Python環境で直接スクリプトを実行していただくことも可能です。
